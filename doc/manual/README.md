# Mahogany Manual

This directory contains information on how to customize Mahogany. It
can be built as a PDF or HTML file by running `make doc` in the root
directory. Prebuilt versions may also be found as a result of the
[latest Action workflow under "build artifacts"](https://github.com/stumpwm/mahogany/actions/workflows/documentation.yml?query=branch%3Amaster).

Note that the links to other sections in the documentation in these
files may be broken when viewed in the GitHub interface.
